# Orchestrator Evaluation Rubric

This rubric is used to evaluate the performance of AI orchestrators against the AI Orchestrator Kata.

## Questions
1. Does the feature work, per the feature's AC?
2. What Model(s) did you use, for what work, and their estimated Percentages?
3. How many Lines of Code were changed?
4. How long did it take the orchestrator from start to finish?
5. What is the final code-coverage score?
6. What if any supporting documentation did your change add?
